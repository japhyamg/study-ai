## Notes / decisions
- Source uses **tailwindcss 3 + shadcn/ui + recharts + lucide-react**. Laravel port is **server-rendered Blade + vanilla JS** (per your earlier decision). Charts are **hand-built CSS/SVG** (no recharts equivalent needed; recharts is canvas/JS-charting which conflicts with "no AI slop" minimalism).
- **AI generation pipeline parity**: teacher upload (`/teacher/materials/create`) → AI processes content via `GenerateAiContent` job → `AiContentService::runJob` → `AiService::generateStudyContent`/`generateStudyGuide` (OpenAI-compatible, retry logic, JSON sanitizer ported from `src/lib/ai/groq.ts`) → saves to `flashcards`/`questions`/`study_guides` tables → teacher reviews/approves via `materialsApproveAll` → `published=true` → visible to students. The `Question` model (not `ExamQuestion`) is used for material-bank questions; `saveQuestions` fixed to write there so generated questions appear on student/material views.
- **Question settings threading**: `question_count` (3–30) + `question_types[]` (multiple-choice/true-false/fill-blank/short-answer) captured in upload form, validated in `TeacherController::materialsStore` / `MaterialController::generate`, stored in `ProcessingJob.result` JSON, read by `AiContentService::runJob` and passed as `questionCount`/`questionTypes` options to `AiService::generateStudyContent`.
- Source has **dark mode** (theme-provider + toggle). Your design decision: single authoritative theme (amber editorial-restraint). I'll keep **light-only** as decided — no theme toggle, to avoid AI-slop toggle chrome. Flag if you want dark mode.
- Source `study/[id]` and `teacher/materials/[id]` are the **two biggest** parity gaps (full tabbed hubs). Building these = highest value.
