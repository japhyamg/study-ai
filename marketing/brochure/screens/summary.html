Quadratic Equations : Study Guide

The quadratic formula solves ax² + bx + c = 0. The discriminant b² − 4ac determines the nature of the roots, so pupils can classify any quadratic before solving it.

Key formula
x = (−b ± √(b² − 4ac)) / 2a
The discriminant
Δ = b² − 4ac determines the roots. • Δ > 0 → two distinct real roots • Δ = 0 → one repeated root • Δ < 0 → two complex roots
Worked example
Solve x² − 5x + 6 = 0 → (x − 2)(x − 3) = 0 → x = 2 or x = 3.
